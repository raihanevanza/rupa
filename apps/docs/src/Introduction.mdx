# Rupa

**Rupa** (Indonesian for _form, appearance_) is the design system behind my portfolio apps. One set of tokens
drives every brand and mode; one set of accessible React components uses them.

- **Tokens from one source.** `@rupa-ui/tokens` builds CSS variables, a Tailwind v3 preset, a Tailwind v4 theme,
  typed JS, and a React Native palette from the same JSON. Contrast and chart palettes are checked in CI.
- **Multi-brand, light and dark.** Six brands ship today: _violet_ (Mini ERP), _signal_ (AgentGate), _latte_ (Dompet Rumah, cream and caramel), _ledger_ (BukuBesar, ledger green), _mono_ (portfolio, black and white), and _candy_ (Bola Live, candy pink on cream). Switch with
  `data-brand` and `data-theme` on any element, even nested. Use the toolbar above to try it.
- **Accessible by default.** WCAG 2.2 AA: every story runs axe in CI, interactive components have keyboard tests,
  focus is always visible, touch targets are 44 px on touch screens, and status is never color alone.
- **Guarded against regressions.** Every story is screenshot in light and dark mode and compared on each pull request.

| Package           | What it is                                            |
| ----------------- | ----------------------------------------------------- |
| `@rupa-ui/tokens` | Design tokens for CSS, Tailwind, JS, and React Native |
| `@rupa-ui/react`  | 27 React components and a `ThemeProvider`             |
