# rupa_tokens (Flutter)

[Storybook](https://raihan-evanza-rupa.vercel.app) · [GitHub](https://github.com/raihanevanza/rupa) · [`@rupa-ui/tokens`](https://www.npmjs.com/package/@rupa-ui/tokens)

Design tokens for the [Rupa design system](https://github.com/raihanevanza/rupa) in Flutter: every brand in light and dark, spacing, radius, font sizes, shadows, and motion. The values come from the same source as [`@rupa-ui/tokens`](https://www.npmjs.com/package/@rupa-ui/tokens), so a Flutter app and its web dashboard stay in sync.

`lib/src/tokens.g.dart` is generated by `npm run build -w @rupa-ui/tokens` and committed; CI fails when it is out of date. Change `packages/tokens/src`, never the Dart file.

## Install

The package is not on pub.dev. Depend on it from Git, pinned to a commit or tag:

```yaml
dependencies:
  rupa_tokens:
    git:
      url: https://github.com/raihanevanza/rupa.git
      path: packages/flutter
      ref: main # pin a commit SHA in apps
```

Requires Flutter 3.27+.

## Set up

Register the colors as a theme extension, once per brightness:

```dart
import 'package:rupa_tokens/rupa_tokens.dart';

ThemeData buildTheme(Brightness brightness) {
  final c = RupaColors.of(RupaBrand.iris, RupaMode.of(brightness));
  return ThemeData(
    brightness: brightness,
    scaffoldBackgroundColor: c.canvas,
    fontFamily: RupaFont.family,
    extensions: [c],
  );
}
```

## Use

```dart
final c = context.rupa;

Container(
  padding: const EdgeInsets.all(RupaSpace.s4),
  decoration: BoxDecoration(
    color: c.surface,
    borderRadius: BorderRadius.circular(RupaRadius.xl),
    boxShadow: c.shadowCard,
  ),
  child: Text('Rp 120.000', style: TextStyle(color: c.ink, fontWeight: RupaFont.semibold)),
);
```

| Web token                       | Flutter                                        |
| ------------------------------- | ---------------------------------------------- |
| `--rupa-color-surface-2`        | `c.surface2`                                   |
| `--rupa-color-on-primary`       | `c.onPrimary`                                  |
| `--rupa-color-series-1…5`       | `c.series[0…4]`                                |
| `--rupa-shadow-card`            | `c.shadowCard` (tinted with `c.shadow`)        |
| `--rupa-space-1-5`              | `RupaSpace.s1p5` (6)                           |
| `--rupa-radius-2xl`             | `RupaRadius.xxl` (18)                          |
| `--rupa-font-size-3xl`          | `RupaFontSize.xxxl` (30)                       |
| `--rupa-motion-easing-standard` | `RupaMotion.standard` (`Cubic`)                |
| `data-brand="iris"` + `.dark`   | `RupaColors.of(RupaBrand.iris, RupaMode.dark)` |

Bundle Plus Jakarta Sans in the app under the family name `PlusJakartaSans` (see `RupaFont`).

## Develop
